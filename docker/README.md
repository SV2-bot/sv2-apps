# Hotpath-rs Docker Setup

This docker directory contains the hotpath-rs fork build configuration. It builds
SRI images locally with `--features hotpath` instead of pulling pre-built images.

See [docker/AGENTS.md](./AGENTS.md) for operational details.

For the original upstream documentation, see the upstream `release/v0.4.0` tag at
https://github.com/stratum-mining/sv2-apps/tree/v0.4.0/docker.
